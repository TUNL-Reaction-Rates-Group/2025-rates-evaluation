# The 2025 Evaluation of Experimental Thermonuclear Reaction Rates

This repository contains the RatesMC input files corresponding to the 2025
evaluation of experimental thermonuclear reaction rates.

The evaluation is carried out by a few members of the TUNL nuclear astrophysics
group and is going to be published [here](https://nucldata.tunl.duke.edu/nucldata/index.shtml).

Each evaluated reaction is associated with an input file for the
[RatesMC](https://github.com/rlongland/RatesMC) computer code. Selected output
files are posted [here](https://nucldata.tunl.duke.edu/nucldata/index.shtml).
