# The 2025 Evaluation of Experimental Thermonuclear Reaction Rates

The 2025 evaluation of experimental thermonuclear reaction rates is carried out by Christian Iliadis et al. and is published [here](https://iopscience.iop.org/article/10.3847/1538-4365/ae2bdc).

This repository contains the RatesMC input files corresponding to the evaluation. In addition, the Hauser-Feshbach, TALYS rates (deduced by Stephane Goriely) for estimating reaction rates at elevated temperatures are also included.

Each evaluated reaction is associated with an input file for the [RatesMC](https://github.com/rlongland/RatesMC) computer code. Installation instructions, dependencies, and details on how to run this program can be found [here](https://github.com/rlongland/RatesMC) and within the [Training](https://github.com/rlongland/RatesMC/tree/main/Training) directory inside the RatesMC repository (see RatesMCTraining.org).

The 2025 evaluated reaction rates are published [here](https://astrodata.tunl.duke.edu/build/html/ETR25.html) and can also be found on [Zenodo](https://doi.org/10.5281/zenodo.17610211).
